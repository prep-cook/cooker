- xAI credentials run on the execution contract: generation always streams `/responses` from the Responses request egress, xAI's response rules feed the Responses ingress, compact goes to `/responses/compact`, and token counts stay local. Reasoning replay is keyed by caller, credential and the exact session, and cached only after a response that completed with status `completed` and no upstream error before it, read from the Responses ingress's own parse so it takes no response-stream storage; a turn without a reasoning or tool-call anchor allocates nothing for replay, and each item is charged to the entry and total bounds before it is allocated; replay entries are bounded to 8 MiB each and 256 MiB in total. A request carrying `compaction_trigger` keeps the old route.
